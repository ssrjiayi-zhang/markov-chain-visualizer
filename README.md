# Markov Lab — Interactive Markov Chain Explorer

An interactive web application for visualizing Markov chains, exploring stochastic processes, and analyzing applications in corporate credit risk.

## Features

- **State Graph Visualization:** Interactive representations of states and transition probabilities.
- **Short-Run Analysis:** Branching trees, path probabilities, and state transition simulations.
- **Long-Run Analysis:** Stationary distributions, first hitting times, recurrence, and the Strong Markov property.
- **Financial Risk Modeling:** Corporate credit ratings, survival probabilities, and simplified expected credit loss.
- **Customizable Models:** Editable transition matrices, predefined scenarios, and CSV uploads.
- **Bilingual Interface:** English and Chinese support.

## Technologies

- HTML
- CSS
- JavaScript
- Markov Chains and Stochastic Processes
- Probability and Financial Risk Modeling

## Project Purpose

This project combines mathematical concepts with interactive visualization to make Markov chains more intuitive and demonstrate their applications in quantitative risk analysis.

The corporate credit risk module illustrates how transition probabilities can be used to analyze rating migration, default risk, and expected credit loss.

## Limitations

The financial risk analysis uses simplified modeling assumptions and illustrative transition probabilities. Results are intended for educational exploration rather than real-world financial forecasting.
